THE SYSTEM

01

Start with Shopify Dawn.

The free Dawn theme supplies the commerce foundation.

layout/theme.liquid is the document shell. JSON templates choose sections for each page. Dawn's native sections and snippets handle product information, variants, collections, search, filters, cart, and accessibility patterns.

layout/theme.liquidtemplates/snippets/
Liquid runs on Shopify. GitHub Pages serves static files and cannot execute the theme.
02

Compose the homepage.

A JSON template sets the homepage order and section settings.

templates/index.json places the MODU hero first, the benefits second, and Dawn's featured collection third. The featured collection points to all, so it can display real products after they are entered in Shopify.

templates/index.jsonfeatured-collection.liquid
"order": ["modu_hero", "modu_benefits", "featured_collection"]
URL / -> templates/index.json -> each listed section's Liquid file
03

Build the custom Liquid sections.

The Shopify theme editor exposes the custom content fields.

sections/modu-hero.liquid renders the headline, links, and CSS device illustration. Its schema defines editable fields. sections/modu-benefits.liquid loops over three editable benefit blocks.

modu-hero.liquidmodu-benefits.liquid
The device visual uses CSS. No paid image, font, or animation package is needed.
04

Apply the design system.

Theme settings and CSS create a consistent identity.

config/settings_data.json sets color schemes, cart drawer, page width, and animation defaults. assets/modu.css styles the hero, device, benefits, hover states, responsive layouts, and reduced-motion behavior. layout/theme.liquid loads the MODU assets globally.

settings_data.jsonmodu.cssasset loading
05

Wire motion and scrolling.

CSS drives the visual motion, while a small script handles reveal timing and wheel easing.

CSS transitions handle reveals and hover motion, and CSS view timelines add scroll-linked parallax where supported. IntersectionObserver only applies reveal classes. Each eligible mouse-wheel step adds to a target. A requestAnimationFrame loop eases the current scroll position toward that target using elapsed frame time. Fine touchpad deltas, touch input, keyboard input, nested scroll areas, and reduced-motion settings remain native.

06

Keep native commerce features.

Shopify handles shopping. Merchant settings supply the business rules.

Dawn product templates render real products and variants. Collection and search templates provide discovery. Cart uses the drawer setting. Checkout runs through Shopify, while payments, tax, shipping, markets, policies, inventory, and catalog data are configured in Shopify admin.

product.jsoncollection.jsoncart-drawer.js
07

Publish the public site.

GitHub Pages serves the shared visual system from the docs folder.

docs/index.html contains the page structure. docs/style.css styles it. docs/motion.js handles navigation, reveals, and wheel easing. GitHub Pages serves docs/ from the main branch at a github.io URL. This public site has no Shopify catalog or checkout connection.

docs/Open live site
08

Validate and launch Shopify.

These are the remaining steps to make the store sellable.

  1. Create or access a Shopify store and upload the theme files.
  2. Add real product photos, descriptions, variants, prices, inventory, and weights.
  3. Create Desk, Charging, and Travel collections, then build navigation.
  4. Configure payments, taxes, shipping zones, markets, policies, and contact details.
  5. Set hero links and featured collection in the theme editor.
  6. Test mobile layout, search, filters, variants, cart, and checkout.
  7. Run test orders for the intended shipping destinations before publishing.
